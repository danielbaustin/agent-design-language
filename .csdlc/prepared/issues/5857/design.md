# First-Birthday Core Sprint Design

## Purpose

Coordinate WP-08 through WP-13A, WP-15, and WP-16 as one evidence-producing
birthday core while preserving child issue ownership.

## Execution Contract

- Establish birth and identity contracts before continuity and memory work.
- Run dependency-ready memory, capability, profile, and learning lanes in parallel.
- Converge witnesses and receipt only after their evidence producers land.
- Finish with one internally consistent birthday review packet.

## Non-Goals

- v0.93 governance, legal personhood, or production citizenship.
- Implementing child code in the umbrella.

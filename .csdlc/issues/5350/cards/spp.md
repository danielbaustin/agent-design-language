## Invariants

- The #5337 corpus is immutable input and every machine-authoritative case remains mandatory
- Both subjects and every dependency proof are exact-revision and digest bound
- Normalization never hides semantic, ordering, diagnostic, exit, or signature differences
- No mismatch is silently ignored or deferred
- Runtime and WP-10A overlays preserve their owners and cannot compensate for an ADL corpus blocker
- Preparation changes issue-local lifecycle paths only and leaves main/product/Runtime v2 untouched

## Risks

- A moving ADL v2 binary or selector can make a comparison irreproducible
- Overbroad normalization can turn a regression into a false match
- Intentional-difference language can become an unreviewed waiver
- Runtime fixture or metadata evidence can be mistaken for live production-component parity
- Issue closure can be mistaken for terminal typed proof and ancestry
- A new comparator can duplicate the mature #5337 harness and grow unnecessary code

# ADL v2 Core

ADL v2 is planned to own the six-primitives language core, deterministic
compiler, portable records interface, thin CLI, and generation selector.

It must not own Runtime v3 execution behavior or C-SDLC v2 lifecycle records.

Required proof comes from `#5336`, `#5337`, `#5338`, `#5339`, `#5340`, `#5342`,
`#5345`, and `#5350`.

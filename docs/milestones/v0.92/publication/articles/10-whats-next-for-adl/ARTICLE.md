# What's Next for ADL

This series has described an architecture built from separations.

A proposal is not authority. A valid tool schema is not permission. A hypothesis is not evidence. A plan is not an outcome. Persistence is not identity. A security exercise is not certification. A social model is not another mind.

Those distinctions can sound cautious. Together, they make ambitious agent systems easier to reason about. ADL's next phase is to connect more of them in one witnessed runtime without relaxing the evidence bar.

## The foundation so far

ADL has accumulated implemented, bounded surfaces across several generations of work.

Typed contracts describe tools, capabilities, lifecycle state, runtime packets, and evidence. Governed-execution components mediate signed authority and one-shot permits. Bounded Gödel experiments preserve hypotheses, variants, evaluation, and adoption decisions. Runtime foundations represent memory, continuity, citizen state, and Theory of Mind. Red/blue security work frames adversarial testing as a governed loop. C-SDLC applies the same principles to software development.

These parts are not a completed artificial society. They are the engineering substrate from which stronger claims can eventually be tested.

## The v0.92 identity challenge

ADL's active v0.92 milestone is framed around the first true Gödel-agent birthday.

The word “birthday” is intentionally stronger than “startup.” The planned acceptance boundary, set out in Article 3, turns on identity architecture, continuity across cycles, witnessed memory, and a citizen-facing receipt.

Earlier work can create test citizens, snapshots, wake records, and persistent processes. Those are prerequisites, not substitutes for the event.

At the time of this article packet, v0.92 remains active development and release readiness is not claimed. Its work packages are dependency-gated and issue-owned. The birthday belongs in a future evidence record, not in anticipatory copy.

## Learning without hidden mutation

The Gödel-Hadamard-Bayes loop and bounded experiment system create a basis for learning, but fuller adaptive learning requires more.

ADL's roadmap includes an Adaptive Learning DAG: a governed path from evaluation feedback to stateful adaptation and policy-controlled reasoning-graph change. The design challenge is to preserve provenance and rollback as learning becomes more structural.

Which evidence caused a graph change? Which identity adopted it? Can a reviewer compare the prior and resulting behavior? Can policy prohibit a class of mutation? Can the system recover without losing the history of why it changed?

The goal is not unbounded recursive self-improvement. It is an agent that can improve through explicit, inspectable transitions.

## Tools, communication, and the wider world

UTS and ACC provide a current foundation for governed tools. Future work can expand portability, invocation semantics, provider integration, and transport while preserving the rule that description and authority remain separate.

ADL also has an Agent Communication and Interaction Protocol lineage. v0.92 plans schema and transport-readiness work, including an optional WebSocket carrier proof. Transport is not social legitimacy: authenticated messages still need identity, policy, visibility, and runtime admission.

As agents communicate across processes and eventually across polises, distributed authority and continuity become harder. A signed message proves something about provenance; it does not settle trust, standing, or interpretation.

## Security that remembers

Continuous adversarial verification points toward security systems that retain attack and defense evidence as durable knowledge.

The next challenge is integration. Security agents need bounded targets, safe fixtures, governed tool access, replayable traces, and a route for mitigations through ordinary review. Learned defenses need provenance and regression tests. Negative results need careful wording.

The intended result is not an autonomous attacker roaming infrastructure. It is a runtime that can examine declared surfaces continuously while remaining subject to the same governance it tests.

## A product surface through CodeFriend

CodeFriend offers a practical route for ADL ideas to help engineering teams before the inhabited runtime is complete.

The planned alpha combines external-repository ingestion, evidence packets, architecture cognition, specialist review, executable governance, diagrams, remediation planning, tests, and structured reporting for external readers. Its success should be judged by whether a real operator can run it against a bounded repository and understand both the findings and their evidence; no external customer delivery is claimed here.

That product remains planned rather than shipped. The distinction gives the team room to prove usability, reliability, redaction, and delivery instead of treating an internal skill collection as a finished service.

## Economics and society remain open

Long-lived agents will consume compute, memory, attention, and bandwidth. They will form beliefs about one another, inherit norms, negotiate, and encounter conflict.

ADL has foundations and proposals for these domains, but many questions remain unknown. Which allocation mechanisms are fair? How should identity-critical memory compete with immediate utility? How can reputation remain correctable? What rights or duties, if any, should attach to persistent artificial actors?

Engineering can make these questions explicit. It cannot answer them by itself.

## The standard for the next claim

ADL's roadmap is broad, but its most important commitment is methodological: stronger claims should require stronger evidence.

A future release should be tied to closed work, passing validation, reviewed artifacts, and witnessed runtime behavior. A birthday claim should have continuity evidence. A learning claim should identify the adopted change. A safety claim should state its threat model and limits. A product claim should describe what a user can actually run.

That standard makes the project easier to challenge. Readers can inspect the repository, question a boundary, reproduce a focused proof, or point out where language outruns evidence.

What comes next for ADL is therefore not one grand reveal. It is a sequence of governed transitions toward agents that can persist, learn, cooperate, and act while leaving accountability intact.

# Source Packet: Continuous Adversarial Verification

## Brief

- Audience: application-security teams, security researchers, and agent-platform operators.
- Promise: frame security as a continuous, bounded, evidence-producing runtime loop.
- Angle: red, blue, and purple roles should create replayable knowledge rather than episodic reports.
- Series role: extend governed execution into continuous defensive learning.

- Current: ADL has red/blue architecture, bounded security bridge surfaces, and durable evidence conventions.

- Planned: broader automated adversarial-security execution and integration in later work.

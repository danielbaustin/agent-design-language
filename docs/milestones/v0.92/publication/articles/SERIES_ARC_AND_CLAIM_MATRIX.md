# WP-24 Series Arc and Claim Matrix

## Editorial Arc

The series moves from first principles to concrete mechanisms and then to open research. Articles 1-3 establish ADL's system, runtime world, and cognitive loop. Articles 4-7 explain how authority, tools, software delivery, and security constrain external effects. Articles 8-9 explore economic and social dimensions with deliberately narrower claim posture. Article 10 synthesizes the roadmap without announcing an unfinished release.

Each article must stand alone while using the same vocabulary: models propose; trusted runtime components authorize; evidence supports review; plans remain distinguishable from implemented behavior.

## Shared Language Rules

- Use **implemented** only where code, tests, or accepted evidence supports it.
- Use **active** for work currently allocated but not terminally proven.
- Use **planned** or **proposed** for designs without current implementation proof.
- Use **historical** for source drafts retained as lineage.
- Use **unknown** for open empirical or social questions.
- Never use planning documents as release evidence.
- Never imply legal personhood, consciousness, universal safety, certification, customer adoption, or production readiness.

## Citation And Privacy Rules

All evidence links are repository-relative. Public prose paraphrases source material and avoids private prompts, machine-local paths, secrets, unpublished customer information, and unsupported quantitative claims. Source packets remain reviewer-facing companions; the articles should be readable without requiring access to internal lifecycle records.
